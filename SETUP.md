# Setup

Nothing here needs secrets, tokens or workflows.

## Publish

1. Make sure a **public** repo named exactly `kavya-216/kavya-216` exists. GitHub shows its `README.md` on your profile.
2. Put `README.md`, `gen_assets.py`, and the `assets/` folder at the repo root.
3. Commit and push. The images use relative paths, so they work as-is.

## Add project links

I couldn't list your repositories from this session, so no project links are in the README. To add one, put it on the project name, for example in `README.md`:

```md
**[Udaan](https://github.com/kavya-216/<repo-name>)**<br>
```

For Mitra, add a line under the plate (`**Code.** [repo](https://github.com/kavya-216/<repo-name>)`).

## Change the artwork

All SVGs are generated by one script, so text and colours live in one place:

```bash
python3 gen_assets.py              # rewrites assets/*.svg
```

Colours are the constants at the top (`BG`, `INK`, `CY`, `MG`, `LM`). The falling code rain is seeded, so it only changes if you change the seed. The hero's three network outputs and the ticker words are plain lists in `hero()`. All motion is SVG animation (no JavaScript); if a viewer doesn't animate it, they see a complete static frame.
